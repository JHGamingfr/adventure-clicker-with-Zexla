# Meme Soundboard Website

A lightweight, no-build meme soundboard you can run directly in the browser.

## Features
- 12 meme sound pads with keyboard shortcuts.
- Random meme button for instant chaos.
- Stop-all button to cut every active sound.
- Volume slider controlling speech and synthesized effects.
- Fully static site (`index.html`, `styles.css`, `script.js`).

## Run locally
Open `index.html` directly in a browser, or serve with a static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
