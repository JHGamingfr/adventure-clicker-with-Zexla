# Adventure Clicker with ZEXLA

This repo contains the single-page ZEXLA landing experience for clicker game support.

## Quick start

1. Open `index.html` in a browser.
2. Update the `supported` array in the script to include real CrazyGames URLs.
3. Replace the download placeholder inside the `download-btn` handler when you have a ZIP hosted.

## Notes

- The support bar lets you paste a game URL and check if it is in the supported list.
- The "Get Code?" button appears when a supported URL is detected.
